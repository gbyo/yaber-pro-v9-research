# Security policy

This repository documents research on a rooted/debuggable projector platform.

Do not open an issue containing:

- public-IP or private-LAN addressing tied to your home
- MAC addresses
- Wi-Fi credentials
- tokens/cookies
- private signing keys
- device serial numbers
- raw full-device backups

If you find a security issue specific to a currently sold device or service, disclose it responsibly to the relevant vendor before publishing exploit details.
